Visual learning · no Canvas required

Ask Gemini to show something you can explore.

You want to move a control and see what changes, rather than read instructions for building an app.

Start in an ordinary Gemini chat

Open a new conversation and select Pro if your account offers it. Ask Gemini to help you visualize a concept. Describe one useful control, such as a slider. You do not need to ask for HTML, JavaScript or a downloadable file.

Google documents interactive visualizations directly in chat. This is different from asking Canvas to build an app. It does not guarantee that every request or account will produce the same interface.

Try a simple concept first

Help me visualize a pendulum.
Show an interactive simulation here with a length slider
and a play/pause button. Ask me to predict how changing
the length affects the period before I try it.

Check that the slider actually changes the simulation. An image of a slider is not a working control.

Workshop example: positive tests

PPV is the fraction of positive tests that are true positives. Prevalence is the fraction of people with the disease in this fictional example.

Help me visualize how disease prevalence changes the meaning
of a positive test. Show an interactive visualization in this chat,
with a prevalence slider, not an HTML code block.
Use 10,000 fictional people. Keep sensitivity and specificity at 90%.
Show true positives, false positives and PPV as I move the slider.
Ask me to predict what changes from 10% to 1% prevalence.

Only getting text or code?

Please show an interactive visualization directly in this conversation.
I want to move a prevalence slider and see the counts change.
Do not give me code or instructions for building an app.
If this chat cannot display an interactive visualization,
tell me plainly.

If a working visualization still does not appear, use the workshop PPV app. It opens in the browser without Canvas, installation or an AI account. This is a prepared teaching tool, not the result of your Gemini request.

You can also keep learning in text: ask Gemini for a small table at two prevalence values, predict the change, and check the arithmetic. You do not need to purchase a plan to finish this exercise.
