# Part 5 Presenter Runbook — Verify, Think, Stay Honest

Target time: **8 minutes**, followed by **20 minutes Q&A**.

## Purpose

Part 5 closes the loop opened in Part 0. Students should leave with a practical boundary:

> AI can support learning, but the final responsibility for understanding, verification, privacy, and academic integrity remains with the student.

## Timing

| Time | Slide focus | Presenter action |
|---:|---|---|
| 0:00–0:40 | Title | Transition from Exercise 3. “Now that AI can critique us, we need to know when not to trust it.” |
| 0:40–1:20 | Three risks | Reconnect THINK / VERIFY / INTEGRITY to Part 0. |
| 1:20–2:20 | Hallucination types | Explain that plausible errors are more dangerous than absurd errors. |
| 2:20–3:20 | Verification ladder | Give one example: formula looks right, but course convention differs. |
| 3:20–4:20 | Checkable-answer prompt | Show how to ask for assumptions, source support, inference, verification targets, and test cases. |
| 4:20–5:20 | Privacy | Mention medical, business, classmates' work, unpublished research, and internship data. |
| 5:20–6:30 | Academic integrity | Use the three-zone boundary: usually appropriate / check policy / do not outsource. |
| 6:30–7:20 | Disclosure | Show the four things to record: tool, purpose, student role, verification. |
| 7:20–8:00 | Final checklist | End on independent understanding, then open Q&A. |

## Key wording

Use careful language:

- Do not say “AI use is cheating.”
- Say “AI use depends on task, course policy, and what cognitive work you outsourced.”
- Do not say “Notebook never hallucinates.”
- Say “Source-grounded tools can reduce hallucination, but you still need to check whether the cited source supports the claim.”
- Do not say “Comparing two models verifies the answer.”
- Say “Comparing two models can reveal instability; final verification should use course materials, original sources, examples, or human judgment.”

## Local policy slot

If the host university provides an official generative-AI or academic-integrity policy, add one extra slide before the final checklist:

```markdown
---

<section>
```

Do not paraphrase policy loosely if exact wording is available.

## Q&A seed questions

If students are quiet, use one of these:

1. “What is one use of AI that feels helpful but maybe dangerous for learning?”
2. “What course task are you unsure whether AI is allowed for?”
3. “Where do you personally draw the line between feedback and outsourcing?”
4. “Which tool would you use for your own course tomorrow: Gemini, DeepSeek, or Notebook?”
