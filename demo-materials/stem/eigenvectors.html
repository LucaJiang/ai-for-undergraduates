When is Av a scalar multiple of v?

A matrix transforms a vector. A nonzero vector v is an eigenvector when Av = λv for some scalar λ. For a positive λ the orientation is preserved; a negative λ reverses it; λ = 0 sends v to zero. The zero vector itself is not an eigenvector.

Source note

With A = diag(2,1), multiplying (x,y) gives (2x,y). The first coordinate doubles; the second is unchanged. An eigenvector condition must use the same λ for every coordinate. For v = (1,1), matching only the first coordinate does not establish the condition.

A stretching-sheet analogy fits this example, but not every matrix. This page uses real diagonal matrices deliberately; it does not claim every real matrix has a real eigenvector.

Two checks — try before opening the key

  1. For A = diag(2,1), compare v = (1,0) and v = (1,1). Which meets the definition?
  2. For A = diag(1,0), does v = (0,1) count? What is λ? Does v = (0,0) count?
