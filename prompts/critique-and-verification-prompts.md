# Critique and verification

Use the canonical templates below. The copyable webpage and this library use the same Markdown source, so there is no second hidden prompt text.

- [Critique my explanation](index.html#prompt-08)
- [Compare two model answers](index.html#prompt-09)
- [Check a claim against a source](index.html#prompt-17)

Do not require the AI to find an error. If the work is correct or evidence is insufficient, it should say so. Verify a proposed correction against the source/definition before accepting it.
